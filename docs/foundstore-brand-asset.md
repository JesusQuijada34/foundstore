# Activo de marca compartido de Foundstore

Las cabeceras y el acceso de Foundstore deben usar `static/logo_foundstore_transparent.png` mediante el macro `render_templates/_foundstore_brand.html`. El activo contiene el símbolo de tienda y el logotipo oficial; en cabeceras compactas se muestra únicamente su zona de símbolo dentro de `.foundstore-brand-icon` para conservar legibilidad.

No se deben introducir monogramas de texto como `FS` o `FD` como sustitutos de la marca.
